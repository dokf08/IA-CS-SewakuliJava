# README - ljr674 PSHT Project Scheduler and Handling Tools

## Introduction
Welcome to **ljr674 Project Organizer**! This application helps manage PHS crew orders for camera, streaming, and other event operations. The system is connected to an **online Supabase database**, so no manual database setup is required.

---

## Installation & Setup

### 1. Prerequisites
Ensure you have the following installed:
- **Java (JDK 11 or later)**

---

### 2. Running the Application
1. Extract `ljr674.zip` (contains necessary assets like images).
2. Place the **lib** folder in the same directory as `ljr674-PSHT.jar`.
3. Open a terminal or command prompt in the folder and run:

   ```sh
   java -jar ljr674-PSHT.jar
